# Madrese — کتابخانه هوشمند معلم

این مخزن فقط برای فایل‌های نصب و آپدیت‌های امضاشده است. کد برنامه خصوصی می‌ماند.

[دانلود آخرین نسخه](https://github.com/hossein26/Madrese-releases/releases/latest)

- Windows x64: فایل `-setup.exe` را اجرا کنید؛ WebView2 آفلاین همراه نصب‌کننده است.
- macOS Apple Silicon: فایل `aarch64.dmg` را باز کنید و برنامه را به Applications ببرید.
- macOS Intel: فایل `x64.dmg` را باز کنید و برنامه را به Applications ببرید.
- آپدیت دستی: تنظیمات ← بررسی نسخهٔ جدید ← دانلود و نصب.
